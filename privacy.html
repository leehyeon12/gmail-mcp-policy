개인정보처리방침 / Privacy Policy

최종 수정일 / Last updated: 2026-09-10

1. 개요 / Overview

Gmail MCP(이하 "본 도구")는 개발자 본인이 자신의 Gmail 계정을 관리하기 위해 만든 개인용 커맨드라인 도구입니다. 본 도구는 공개 서비스가 아니며, 개발자 외의 사용자를 두지 않습니다.

Gmail MCP ("the Tool") is a personal command-line utility built by its developer to manage their own Gmail account. It is not a public service and has no users other than the developer.

2. 수집하는 정보 / Information We Collect

본 도구는 어떠한 개인정보도 수집·저장·전송하지 않습니다. 운영하는 서버나 데이터베이스가 없습니다. 메일 데이터는 사용자의 컴퓨터에서 Google API로 직접 요청되어 화면에 표시될 뿐이며, 외부로 전송되지 않습니다.

The Tool collects, stores, and transmits no personal information. There is no server or database. Mail data is requested directly from the Google API by the user's own computer, displayed locally, and never sent anywhere else.

3. Google 사용자 데이터의 이용 / Use of Google User Data

본 도구는 다음 범위(scope)를 사용합니다.

  • gmail.readonly — 메일 검색 및 조회
  • gmail.modify — 라벨 지정, 보관, 삭제
  • gmail.settings.basic — 메일 필터 생성 및 관리

취득한 데이터는 위 기능을 수행하는 목적으로만, 사용자의 로컬 컴퓨터 안에서만 사용됩니다. 본 도구의 Google 사용자 데이터 이용은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요건을 준수합니다.

Data obtained is used solely to perform the functions above, entirely on the user's local machine. The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 제3자 제공 / Sharing

어떠한 데이터도 제3자에게 제공, 판매, 양도하지 않습니다. 광고·분석 도구를 사용하지 않습니다.

No data is shared, sold, or transferred to any third party. No advertising or analytics is used.

5. 인증 정보 보관 / Credential Storage

OAuth 인증 토큰은 사용자 컴퓨터의 운영체제 키체인(macOS Keychain)에만 저장되며, 외부로 전송되지 않습니다. 사용자는 Google 계정 연결 설정에서 언제든지 접근 권한을 철회할 수 있습니다.

OAuth tokens are stored only in the operating system keychain on the user's own computer and are never transmitted. Access can be revoked at any time from the user's Google Account settings.

6. 데이터 보관 및 삭제 / Retention and Deletion

본 도구는 메일 데이터를 별도로 보관하지 않습니다. 도구를 삭제하고 위 링크에서 권한을 철회하면 모든 접근이 종료됩니다.

The Tool retains no mail data. Deleting the Tool and revoking access ends all access.
